# Phase 1: модель данных

Схема БД не меняется. Всё, что ниже, — новые ключи в поле `data` (JSON) существующих узлов и одно
новое ребро.

## Задача (`NodeType::Task`)

Существующие поля используются как есть: `Node.created_at` — время заведения,
`data.$.status` — состояние (`backlog` / `active` / `blocked` / `done`), `data.$.priority`,
критерии приёмки.

Добавляется:

| Ключ | Тип | Смысл | Когда пишется |
|---|---|---|---|
| `activated_at` | RFC 3339 | взята в работу | при переходе в `active` |
| `closed_at` | RFC 3339 | закрыта | при переходе в `done` |
| `resolution` | объект | чем решена | при закрытии |
| `evidence` | массив объектов | улики по задаче | при каждом прогоне |
| `last_edit_at` | RFC 3339 | последняя правка кода | при срабатывании хука правки |
| `declined_ripe_at` | RFC 3339 | человек отклонил предложение закрыть | при отказе |

Все поля опциональны. Задача без них — обычная задача, заведённая до этой фичи.

### `resolution`

```json
{
  "commit": "c466933",
  "pull_request": "https://github.com/Blysspeak/aurelius/pull/21",
  "files": ["crates/aurelius-core/src/graph/lease.rs"],
  "confirmed": true
}
```

`confirmed: false` означает «закрыта без подтверждения» — способ решения неизвестен, и это
записано явно, а не подразумевается пустотой.

### `evidence` (элемент массива)

```json
{
  "command": "cargo test --workspace",
  "exit_code": 0,
  "at": "2026-08-30T09:14:22Z",
  "artifact": ".ulika/artifacts/1756543-8f3a2b11.log",
  "artifact_present": true
}
```

`artifact_present: false` ставится, когда файл артефакта больше не найден: сведения о прогоне
остаются, а ссылка честно помечена как утраченная.

### Переходы состояний

```text
backlog ──activate──> active ──done──> done
   ^                    │                │
   └────вытеснена───────┘                └──reopen──> active
        (взята другая)                     (времена и resolution
                                            остаются как история)
```

Инвариант: в одном проекте не более одной задачи в состоянии `active`. Взятие новой задачи
переводит прежнюю в `backlog`, сохраняя её `activated_at`, `evidence` и `last_edit_at`.

### Производное состояние: созревшая

Не хранится. Задача считается созревшей, когда все условия истинны одновременно:

1. `status == "active"`;
2. есть `last_edit_at`;
3. в `evidence` есть элемент с `exit_code == 0` и `at` позже `last_edit_at`;
4. `declined_ripe_at` отсутствует или старше `last_edit_at`.

Условие 4 и даёт правило «отклонённое предложение не повторяется, пока не появится новая работа».

## Координата секрета (`NodeType::Config`)

```json
{
  "kind": "secret_ref",
  "name": "STRIPE_SECRET_KEY",
  "purpose": "боевой ключ Stripe для приёма платежей",
  "location": "1password://Private/Stripe/api-key",
  "location_kind": "password_manager"
}
```

`location_kind`: `env` | `file` | `password_manager`. Значения секрета нет ни в одном поле, и
запись отклоняется, если содержимое `location` похоже на само значение.

## Снимок перед сжатием (`NodeType::Session`)

Существующий тип, меняется только то, каким типом его пишет обвязка. Поля прежние: текст снимка,
метка с проектом и временем, вид памяти `episodic`, ключ идемпотентности по отпечатку текста.

## Ребро

Одно новое: задача → узел прогона, тип `verified_by`. Нужно, чтобы улику можно было найти со
стороны прогона, а не только внутри данных задачи. Внутри `data` улика лежит для быстрого чтения
без обхода графа; ребро — для связности.
